# ADR 0002: 以不可變出席事件衍生上場率公平狀態

## Status

Accepted

## Context

配對公平目標由「同一活動內上場總場數接近」改為「每單位可上場在場時間的上場次數接近」。可上場在場時間只累積參賽者在場且未自願休息的期間；App 關閉或鎖屏不會停止累積。

現有活動資料只保存目前在場、離場與自願休息名單，沒有每次狀態變更的時間，無法可靠回答某人累積了多少可上場在場時間。新模型還必須支援中途加入、離場後重新加入、手動重啟個別公平計算期、比賽刪除後重算、App 重開及 CSV round-trip。

只保存目前累積分鐘或最終上場率雖然簡單，但會丟失推導依據；在比賽刪除、活動仍在進行或資料匯出後，無法可靠重算。覆寫完整區間則會讓歷史狀態反覆變動，難以核對變更來源。

## Decision

- 以不可變的時間事件作為可上場狀態的權威紀錄。事件至少涵蓋加入、離場、自願休息開始、自願休息結束與公平計算期重啟，並綁定活動、參賽者與事件時間。
- 可上場在場時間由事件序列衍生；只有在場且未自願休息的區間累積。離場或自願休息只暫停，重新加入或取消休息後沿用同一公平計算期。
- 同一活動內重新加入不會重啟公平計算期。使用者可另行明確執行「重置上場率」，為單一參賽者建立新的公平計算期，使配對用場數與可上場在場時間歸零；整日統計、比賽歷史與 Rating 不受影響。
- 沒有進行中比賽時，重置立即生效。若該參賽者正在比賽，操作先排定，待該場完成或取消後才建立新公平計算期；該場及其剩餘時間完整保留於舊期。
- 完成並記錄的比賽依最終實際上場名單計數；強制記錄但不計 Rating 的比賽仍計數。取消或未完成的比賽不計數。刪除比賽時由剩餘比賽與凍結的公平計算期歸屬重算。
- 時間事件、公平計算期及比賽的計算期歸屬必須保存於本機資料並納入 CSV 匯出／匯入。活動結束後保留資料，但第一版不在歷史 UI 顯示。
- 升級沒有時間事件的既有進行中活動時，不推測不存在的加入時間；在遷移當下為目前在場者建立新的公平計算期，既有比賽、整日統計與 Rating 保留。已結束舊活動不補造出席事件。
- 若時間事件無法可靠重播，配對顯式降級為既有的活動總場數公平演算法。降級期間常駐顯示目前未使用上場率公平，停止把新狀態追加成貌似可靠的上場率歷史，並保留原始資料匯出能力。
- 降級狀態提供「為所有目前在場者重啟公平計算期」的修復操作；操作成功後從當下建立新的事件權威邊界並恢復上場率配對，降級期間完成的比賽保留於整日統計與 Rating，但不回填為可靠的上場率歷史。

## Consequences

- 任一上場率都能追溯至明確的可上場狀態事件與已完成比賽，而非不可解釋的累積值。
- App 關閉、鎖屏或重新整理後可依時間戳繼續計算；只要活動未結束且狀態未變，可上場時間會持續累積，包括使用者忘記結束活動的長時間空白。
- 刪除比賽可以只重算場數，不必猜測或改寫出席時間。
- 公平計算期重啟不會刪除真實歷史，但需要比賽在開打時保存計算期歸屬，資料模型與遷移比單一累積欄位更複雜。
- 不提供歷史事件時間編輯；操作錯誤以建立新的公平計算期修復。此操作會讓該參賽者像剛加入者一樣重新進入低上場率排序，系統不阻止現場主辦者使用此權限。
- 新行為必須以事件重播、CSV round-trip、App 重開、比賽刪除及比賽進行中重啟等情境驗證。
